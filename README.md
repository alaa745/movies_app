**About the Project**  

Welcome to the **Movie App**! 🎥 This project is a mobile application built with **Flutter**, designed to provide users with a seamless movie discovery and management experience. The app follows the **MVVM (Model-View-ViewModel)** pattern and adheres to **Clean Architecture** principles for scalability, testability, and maintainability.  

### Features  
- **Movie Discovery**: Browse the latest movies fetched from an external API.  
- **Detailed Movie Information**: View detailed information about each movie, including synopsis, ratings, and more.  
- **Local Storage**: Save your favorite movies locally using **SQFlite** for offline access.  
- **Responsive UI**: Enjoy a sleek and responsive design optimized for all screen sizes.  
- **Clean Architecture**: Ensures separation of concerns and modularity for ease of extension.  

### Technologies Used  
- **Flutter**: For building a cross-platform mobile app.  
- **MVVM Pattern**: To manage UI logic and state effectively.  
- **Clean Architecture**: For a well-structured and maintainable codebase.  
- **API Integration**: To fetch movie data dynamically.  
- **SQFlite**: For storing movies locally and enabling offline capabilities.  

### Getting Started  
1. Clone the repository.  
2. Run `flutter pub get` to fetch dependencies.  
3. Configure the API keys in the project.  
4. Run the app using `flutter run`.
